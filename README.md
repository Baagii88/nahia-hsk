# Нахиа · Хятад хэл 🌱

Монгол интерфэйстэй, утас болон компьютерт зориулсан HSK суралцах вэб апп.

## Боломжууд

- HSK 1–6, 7–9 түвшний 11,073 үгийн бичлэг, пиньинь, утга.
- 10,900 дуудлагын файл, үг хадгалах, хайлт.
- Картын давтлага, давтах хугацаа тооцох, 10 асуулттай сорил.
- 593 дүрмийн эх материал хятад хэлээр.
- Өдрийн зорилго, ахиц, нөөц хуулбар татах ба сэргээх.
- Утасны нүүр дэлгэцэд нэмэх, эхний удаа нээсний дараа үндсэн өгөгдлийг интернэтгүй ашиглах.

Монгол тайлбар зарим анхан шатны үгэнд бий; бусад тайлбар англи хэлээр. Ахиц тухайн хөтөчдөө хадгалагдана, автоматаар төхөөрөмж хооронд синк хийхгүй.

## Ажиллуулах

```sh
python build.py
python -m http.server 4174 --directory dist
```

Хөтөч дээр http://localhost:4174 нээнэ. Нэмэлт сан суулгах шаардлагагүй.

GitHub Actions нь main салбарын өөрчлөлт бүрийг GitHub Pages-д нийтэлнэ. Дуудлагын файлуудыг repository-д оруулахад хялбар байлгахын тулд audio-1.zip, audio-2.zip, audio-3.zip гэсэн багцад хадгалсан. build.py эдгээрийг автоматаар задална.
